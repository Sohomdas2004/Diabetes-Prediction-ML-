# 🩺 Diabetes Prediction using Machine Learning

## 📌 Overview

This project focuses on predicting whether a person is likely to have diabetes based on medical attributes. It uses supervised machine learning algorithms to analyze health data and generate predictions that can help in early detection.

---

## 🎯 Problem Statement

Diabetes is a serious health condition that requires early diagnosis to prevent complications.
The goal of this project is to build a machine learning model that can predict diabetes based on features like glucose level, BMI, age, etc.

---

## 📊 Dataset

* The dataset used is based on medical diagnostic data (commonly the Pima Indians Diabetes Dataset).

* Features include:

  * Pregnancies
  * Glucose
  * Blood Pressure
  * Skin Thickness
  * Insulin
  * BMI
  * Diabetes Pedigree Function
  * Age

* Target variable:

  * `0` → Non-diabetic
  * `1` → Diabetic
